# CAM++ model notice

The accepted ONNX file is the 3D-Speaker CAM++ VoxCeleb 16 kHz speaker-embedding model distributed
with the k2-fsa/sherpa-onnx speaker-recognition model assets. The catalog pins its exact byte size
and SHA-256. Review the upstream model card, training-data terms, and notices before redistribution.

Source: https://github.com/k2-fsa/sherpa-onnx
