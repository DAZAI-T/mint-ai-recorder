# セキュリティポリシー / Security Policy

## サポート対象バージョン

セキュリティ更新は、原則として最新の公開版に対して提供します。

| バージョン | サポート |
| --- | --- |
| 1.0.x | 対象 |
| 1.0.0より前 | 対象外 |

## 脆弱性を報告する

脆弱性の詳細を公開Issue、Pull Request、Discussionへ投稿しないでください。GitHubの[非公開の脆弱性報告](https://github.com/DAZAI-T/mint-ai-recorder/security/advisories/new)から報告してください。

報告フォームを利用できない場合は、脆弱性の詳細を記載せず、Issueに「Security contact request」とだけ投稿してください。安全な連絡方法を案内します。

報告には、可能な範囲で次の情報を含めてください。

- 影響を受けるアプリのバージョン
- Androidのバージョンと端末情報
- 問題の概要と想定される影響
- 再現手順または概念実証
- 回避策がある場合はその内容

会議の録音、文字起こし、議事録、APIキー、パスワード、回復キー、署名鍵などの機密情報は添付しないでください。ログを添付する場合は、個人情報や認証情報を削除してください。

受領後7日以内の確認、14日以内の初期評価を目安に連絡します。修正内容と公開時期は、影響範囲を確認したうえで報告者と調整します。

## Reporting a vulnerability

Do not disclose vulnerability details in a public Issue, Pull Request, or Discussion. Please use [GitHub private vulnerability reporting](https://github.com/DAZAI-T/mint-ai-recorder/security/advisories/new).

If the private reporting form is unavailable, open an Issue containing only the title “Security contact request” and no vulnerability details. We will provide a secure contact method.

Include the affected app version, Android version and device, impact, reproduction steps or proof of concept, and any known workaround. Do not attach meeting recordings, transcripts, minutes, API keys, passwords, recovery keys, signing keys, or other sensitive data. Remove personal and authentication information from logs before attaching them.

We aim to acknowledge reports within 7 days and provide an initial assessment within 14 days. Disclosure timing will be coordinated after the impact and remediation have been assessed.
